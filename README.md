# OperateServices — Staffing & Services (Next.js)

Production-ready Recruiting & Staffing Agency platform for **OperateServices**, built with Next.js 16 App Router, Tailwind CSS v4, dynamic programmatic SEO, OpenGraph metadata, and structured data (JSON-LD).

## Tech Stack

- **Next.js 16** (App Router)
- **React 19** + **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/postcss`)
- **Lucide Icons** & **Motion**
- **SEO**: Dynamic sitemap (`sitemap.ts`), `robots.ts`, OpenGraph & Twitter Cards, Organization & WebSite JSON-LD schemas.

## Getting Started

**Prerequisites:** Node.js (v18+)

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the application.

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Start production server:**
   ```bash
   npm start
   ```

5. **Run test suite:**
   ```bash
   npm test
   ```
